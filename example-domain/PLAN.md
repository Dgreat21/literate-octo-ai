# PLAN — что дальше

_Шаблон. Живой план зарегистрирован в `mastery/plans/registry.csv` (rule и
механика — `AGENTS.md` §7); незарегистрированный план — черновик._

## Этапы

| Этап | Шаги | Гейт (что должно стать правдой) |
|---|---|---|
| 0. Разведка | собрать факты в `INVENTORY.md` | цифры измерены, не оценены |
| 1. Решение | развилки → `DECISIONS.md` | решение записано с причиной |
| 2. Исполнение | шаги с артефактом на каждый | артефакт-файл существует (rule-1) |
| 3. Проверка | верификатор + негативный контроль | проверка падает на сломанном входе |

Этапы соотносятся со статус-тегами задачи трекера — по ним срабатывают
триггеры `mastery/registry.csv`.
