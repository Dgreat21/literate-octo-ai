# example-domain — шаблон домена

Домен — «направление деятельности»: папка в корне контекстной директории,
в которой живёт всё знание по одному направлению работы (см. `AGENTS.md` §3).
Эта папка — образец: файлы показывают стандартный набор и назначение каждого.

## Файлы домена

| Файл | Отвечает на вопрос | Когда читать |
|---|---|---|
| `README.md` | что это за направление, карта файлов | первым, всегда |
| `STATUS.md` | где мы сейчас | перед началом работы в домене |
| `PLAN.md` | что дальше и какими шагами | при планировании |
| `DECISIONS.md` | что решили и почему | при развилке |
| `RISKS.md` | что может пойти не так, у кого владение | еженедельно |
| `INVENTORY.md` | измеренные факты (цифры рождаются здесь — rule-7) | при ссылке на цифру |
| `generated/` | тяжёлые генерируемые артефакты | не читать, генерировать |

Не все файлы обязательны — обязателен только `README.md`. Но если файл о
статусе появился, он называется `STATUS.md`, а не `state.md`/`ГДЕ_МЫ.md`:
синонимы не плодим.

## Жизненный цикл

- Рождение: тема созрела в `.other/<тема>/` → переехала сюда,
  `project.md` стал `README.md`, строка в таблицу доменов `AGENTS.md` §1.
- Смерть: домен не удаляется — папка получает префикс `deprecated_`,
  содержимое не трогается (rule-4).
- Оба события — строки в `work_journal.md`.
