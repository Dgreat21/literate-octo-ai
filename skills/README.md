# skills — витрина частых скиллов

Физическая папка с README и **симлинками на часто необходимые скиллы** —
быстрый доступ без хождения по `mastery/tools/addons/...`.

**Истина — не здесь.** Полный каталог и триггеры «когда что включать» —
`mastery/registry.csv`. Витрина — это кэш для руки, а не реестр:
симлинк добавляется, когда скилл реально зачастил, и убирается, когда перестал.

## Сейчас на витрине

| Симлинк | Зачем под рукой | Реестр |
|---|---|---|
| `xlsx/` | Гант, выгрузки трекера, отчёты — самый частый формат | MST-1 |
| `docx/` | документы заказчику | MST-2 |
| `pdf/` | извлечение и сборка PDF | MST-3 |
| `skill-creator/` | оформление кандидатов из журнала в скиллы | MST-5 |

## Правила

- Добавление/удаление симлинка — событие для `work_journal.md`.
- Симлинки ведут в `mastery/tools/addons/` (в т.ч. в `source/`, который вне git):
  на чужой машине без клонов `source/` витрина будет частично битой —
  `check_refs.py` это покажет.
- Наши скиллы из `by_team/` попадают сюда на общих основаниях, когда зачастят.
