# rule-9: Публикация — осознанный акт

Черновик живёт на кухне (mastery/design_docs/), наружу выходит симлинком
в витрину (design_docs/) — и это делает владелец, не агент. Симлинк и есть
статус published. Снятие с публикации — удаление симлинка.

**Почему.** Опубликованное — обещание внешнему читателю; давать обещания
может только владелец.
