# rule-5: Общие файлы — под локом

Запись в work_journal.md, реестры и любые общие файлы основного дерева —
только под мьютексом (mastery/tools/ctx_lock.py). Параллельная работа
нескольких агентов — в git worktree. Чужой живой лок не ломается.

**Почему.** Два одновременных писателя без лока — молчаливая потеря
чьей-то записи.
