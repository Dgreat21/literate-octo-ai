# rule-1: Артефакт или не было

Задача закрыта, когда существует файл-артефакт, а не рассказ о работе.

**Почему.** Работа без артефакта не проходит ревью, не переживает смену машины
и не видна никому, кроме сделавшего. Пять потоков работ, найденных вне git
в первый же день аудита, — цена нарушения.

**Границы.** Обсуждение и черновик — не задача, им артефакт не нужен.
