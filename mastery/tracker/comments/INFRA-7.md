# Комментарии: INFRA-7

## агент · 2026-08-21 17:00

Ревью макета (разобран из бандла: iOS-каркас + дизайн-система «Organic» +
кликабельный прототип на 9 экранов).

**Сильное, забираю без спора:**

1. **Инвариант честности связи** — «better a dead button than a command
   that silently vanishes». Это тот же принцип, что наш rule про
   авторитетное поле: интерфейс не утверждает того, чего не знает.
2. **Асимметричная цена ответов в approve (1d-ii)**: рискованное «allow» —
   hold, дешёвое «deny» — tap. Ошибка дорогой стороны дороже — трение
   распределено правильно.
3. **1b-iii (digest + одна сырая строка)** — согласен с выбором автора:
   дайджест глазами, одна строка ground truth против «дайджест соврал».
4. **Lock screen как главная поверхность (1f)** и «hearth went quiet —
   one alert only»: без алерт-фатиги, offline — единственное событие.

**Мои голоса по открытым вариантам:** 1c-ii (hold с кольцом — slide
медленный, tap опасный), 1e-ii на home hero + 1e-iii (tok/s) на detail:
«дышит» — для взгляда с метра, «стоит» — для диагностики стола.

**Развилки, которые дизайн вскрывает, но не решает:**

- **Р1: где живёт «daemon folds the tail into steps»?** Предлагаю не
  парсить лог: шаги уже существуют как события dsh-сессии (tool-calls)
  и статусы `pane report-agent`. Нужен маленький `hearthd` на маке поверх
  herdr-сокета и сессий dsh — читающий, не управляющий.
- **Р2: источник approvals.** Headless-прогоны не спрашивают разрешений —
  очередь approvals реальна только для интерактивных сессий (web/TUI)
  и herdr-статуса `blocked`. Значит очередь строится из blocked-агентов
  стада, и «Allow» должен доезжать как ввод в конкретный пейн.
- **Р3: транспорт** — tailnet есть в модели, но порт/протокол не назван;
  наш стек уже стоит на «наружу ничего», SSH поверх tailscale (INFRA-5)
  этому дизайну достаточен для v0 (mosh/ssh-туннель до `hearthd`).

Прототип tap-able: «try next» в самом файле предлагает пересборки
(«swap the log in 1a for 1b-iii») — карточка готова к предметному ревью
по id, а не «нравится/не нравится».
