# Разбор .xlsx средствами stdlib

## Суть

`.xlsx` — это обычный **zip-архив с XML внутри** (Office Open XML). Никакой
бинарщины: `zipfile` открывает, `ElementTree` парсит. Готовый парсер —
`scripts/xlsx_dump.py` (лист → CSV в stdout).

```bash
python3 scripts/xlsx_dump.py файл.xlsx --list      # какие есть листы
python3 scripts/xlsx_dump.py файл.xlsx             # первый лист в CSV
python3 scripts/xlsx_dump.py файл.xlsx "Лист1"     # конкретный лист
python3 scripts/xlsx_dump.py файл.xlsx --raw       # даты оставить serial-числами
```

Что внутри архива:

| Файл | Зачем нужен |
|---|---|
| `xl/workbook.xml` | имена листов и их `r:id` |
| `xl/_rels/workbook.xml.rels` | `r:id` → реальный путь к XML листа |
| `xl/worksheets/sheetN.xml` | ячейки: `<row>` → `<c r="A1" t="s" s="3"><v>…</v></c>` |
| `xl/sharedStrings.xml` | таблица строк; ячейка `t="s"` хранит ИНДЕКС в ней |
| `xl/styles.xml` | `cellXfs` → `numFmtId`: только так дата отличима от числа |

## Процедура

1. `unzip -l файл.xlsx` (или `zf.namelist()`) — убедись, что это zip и есть `xl/`.
2. Прочитай `workbook.xml` + `.rels` → пары «имя листа → путь». **Не** угадывай
   путь как `sheet<sheetId>.xml`.
3. Прочитай `sharedStrings.xml` в список.
4. Прочитай `styles.xml` → множество индексов стилей, означающих дату.
5. Итерируйся по `<row>/<c>` листа, раскладывая значения по индексу из атрибута `r`.
6. Выгрузи в CSV/JSON и **глазами сверь 2–3 строки** с исходником (открой в
   Numbers/LibreOffice/просмотрщике), прежде чем строить на этом выводы.

## Грабли — и ПОЧЕМУ

- **Namespace в каждом теге.** ElementTree возвращает `{http://…/main}row`, а не
  `row`. `find("row")` молча вернёт `None`, и парсер выдаст пустой результат без
  единой ошибки. Всегда ищи с картой namespace (`find("m:row", NS)`) или режь
  префикс через `tag.rsplit("}", 1)[-1]`.
- **`t="s"` — это НЕ строка, а число.** `<v>7</v>` при `t="s"` означает
  «седьмой элемент `sharedStrings.xml`». Без подстановки получишь таблицу
  индексов вместо текста. Отдельно: `t="inlineStr"` кладёт текст в `<is><t>`,
  а не в `<v>`; `t="str"` — результат формулы; `t="b"` — 1/0 вместо TRUE/FALSE.
- **Rich text рвёт строку на куски.** Один `<si>` может содержать несколько
  `<r><t>`; берёшь только первый `<t>` — теряешь хвост («Разбор » вместо
  «Разбор Ганта»). Склеивай все `<t>` поддерева.
- **Даты — serial-числа от эпохи 1899-12-30.** В XML дата неотличима от числа:
  и то и другое `<v>45000</v>`. Тип даёт ТОЛЬКО стиль `s` → `cellXfs` →
  `numFmtId` (14–22, 45–47 и кастомные с `y/m/d/h` в `formatCode`). База
  сдвинута на два дня, потому что Excel считает 1900 високосным: serial 60 =
  несуществующее 1900-02-29. Для дат после 1900-03-01 (то есть всех рабочих)
  смещение `1899-12-30` даёт верный результат; на serial < 61 не полагайся.
- **Пустых ячеек в XML просто НЕТ.** Строка `A,,C` хранится как две ячейки `A1`
  и `C1`. Читая `<c>` по порядку, ты сдвинешь `C` в колонку B — данные тихо
  разъедутся по всей таблице. Позицию бери из атрибута `r` (`"C3"` → колонка 2),
  распарсив буквы в индекс по основанию 26.
- **`dimension ref` может врать.** Атрибут пишет генератор файла, и после правок
  он часто устаревает (заявлено `A1:B2`, а данные до `AA34`). Считай ширину
  фактически — по максимальному встреченному индексу.
- **Merged cells.** `<mergeCells>` хранится отдельно от `<sheetData>`: значение
  лежит в левой верхней ячейке диапазона, остальные пусты. Дырки в шапке — это
  почти всегда объединение, а не потеря данных; при необходимости размножь
  значение по `ref` из `mergeCells`.
- **Не `.xls` и не CSV.** Старый `.xls` — бинарный OLE, `zipfile` даст
  `BadZipFile`; здесь stdlib не поможет (нужен `xlrd` или пересохранение).

## Мини-пример

```python
import zipfile, xml.etree.ElementTree as ET
NS = {"m": "http://schemas.openxmlformats.org/spreadsheetml/2006/main"}

with zipfile.ZipFile("gant.xlsx") as z:
    shared = ["".join(t.text or "" for t in si.iter(f"{{{NS['m']}}}t"))
              for si in ET.fromstring(z.read("xl/sharedStrings.xml")).findall("m:si", NS)]
    sheet = ET.fromstring(z.read("xl/worksheets/sheet1.xml"))

for row in sheet.iter(f"{{{NS['m']}}}row"):
    cells = {}
    for c in row.findall("m:c", NS):
        col = "".join(ch for ch in c.get("r", "") if ch.isalpha())   # позиция из r!
        v = c.find("m:v", NS)
        if c.get("t") == "s":                                        # индекс, не текст
            cells[col] = shared[int(v.text)]
        elif v is not None:
            cells[col] = v.text
    print(cells)
```
