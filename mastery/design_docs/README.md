# mastery/design_docs — кухня диздоков

Здесь живут **все** дизайн-документы: черновики и принятые. Наружу выходит
только симлинк в корневой витрине `design_docs/` — и кладёт его владелец,
не агент (rule-9). Механика — `AGENTS.md` §6.

## Шапка диздока (обязательна)

```markdown
# <Название> — дизайн-документ

- **Версия:** v0.1
- **Автор:** агент / <имя>
- **Дата:** YYYY-MM-DD
- **Дедлайн ревью:** YYYY-MM-DD
- **Задача:** <КЛЮЧ-ТРЕКЕРА>
```

## Правила

- Диздок **синтезирует** доменные файлы (`INVENTORY`/`PLAN`/`DECISIONS`),
  а не заменяет их: цифра рождается в домене, диздок её цитирует (rule-7).
- Принятый диздок не переписывается под новую реальность — выпускается
  новая версия в шапке (rule-6).
