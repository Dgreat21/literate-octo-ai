# design_docs — витрина опубликованных диздоков

Физическая папка с README и **симлинками на опубликованные** дизайн-документы.
Черновики сюда не попадают.

## Кухня и витрина

| Где | Что | Кто читает |
|---|---|---|
| `mastery/design_docs/` (кухня) | все диздоки: черновики и принятые | мы |
| `design_docs/` (витрина, здесь) | симлинки только на **published** | заказчик, команда |

Смысл разделения: черновик — рабочий материал, его можно и нужно менять.
Опубликованный диздок — обещание внешнему читателю. Симлинк в витрине —
это и есть статус published: не колонка в таблице, а физический факт,
который нельзя иметь «наполовину».

## Публикация

Осознанный акт владельца (не агента), после ревью:

```bash
cd design_docs
ln -s ../mastery/design_docs/<имя>.md <имя>.md
```

Снятие с публикации — удаление симлинка (сам диздок на кухне не трогается).
Оба действия — событие для `work_journal.md`.

`check_refs.py` ловит протухшие публикации автоматически: битый симлинк —
это несуществующий путь.
