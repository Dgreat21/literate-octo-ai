# agent-infra — стек агентной инфраструктуры

Первый **живой** домен этого репозитория (не образец, как `example-domain/`):
сборка Herdr + DeepSeek Harness (dsh) внутри octo и каналы удалённого доступа
к агенту. Домен существует, чтобы прогнать сам репозиторий через его же
механику: скиллы с триггерами, задачи в трекере, диздок через кухню, строки
в журнале.

**Префикс трекера:** `INFRA-*` (дефис в имени домена в ключ не переносится).

## Компоненты

| Что | Где | Зачем |
|---|---|---|
| Инструкция стека | [`stack/herdr-dsh-instruction.md`](stack/herdr-dsh-instruction.md) | единственный источник: установка, запуск, удалённый доступ |
| Гайдбук расширения репо | [`stack/EXTENDING.md`](stack/EXTENDING.md) | как заводить в octo новое направление — на этом кейсе |
| Единый вход | [`stack/up.sh`](stack/up.sh) | Herdr-воркспейс `octo`, панель dsh web, панель бота, смоук |
| Headless-обёртка | [`stack/bin/dsh-herdr`](stack/bin/dsh-herdr) | одноразовая задача dsh с репортом статуса в сайдбар Herdr |
| Telegram-бот | [`stack/tg/dsh_tg.py`](stack/tg/dsh_tg.py) | задачи dsh с телефона, long polling, без проброса портов |
| Дизайн мобильного клиента | [`hearth/`](hearth/README.md) | Hearth: телефон как окно к harness'у (макет Дениса, `INFRA-7`) |

## Треки

- **A — сборка**: `up.sh`, панели, смоук (`INFRA-2`, `INFRA-3`).
- **B — удалёнка**: TG-бот (`INFRA-4`), Tailscale + Herdr reattach (`INFRA-5`),
  дизайн родного клиента Hearth (`INFRA-7`).
- **C — исследование**: диздок «dsh как оркестратор стада» (`INFRA-6`),
  черновик на кухне `mastery/design_docs/herdr_dsh_stack.md`.

## Апстримы

`vendor/` — reference-сабмодули исходников, запиненные на проверенные
ревизии (herdr `v0.8.2`, dsh `dsh-v0.1.0-rc.7`). Референс для чтения,
не дерево сборки — см. инструкцию §1.

## Скиллы домена

Зарегистрированы в `mastery/registry.csv`: `herdr-report` (MST-30),
`dsh-headless-job` (MST-31), `dsh-tg-remote` (MST-32). Все три ведут в
инструкцию стека — триггеры смотри в реестре.
